# P28 — Full-scale performance and memory

Status: measured and optimized on the development machine on 23 September 2026; a Windows export now exists, but exported-build profiling and GTX 980-class hardware acceptance remain unverified. Detailed settings, before/after values and limitations are in [performance measurements](../performance.md).

The 5,700 required records and 5,376 initial WORLD records remain intact. A 95 m native visibility limit on small item meshes cut measured visible draws from 11,644 to 4,714 at 1080p. Resting small-item views now stream within 150 m of the player and demote beyond 200 m only after sleep, outside highlight state. Large props, thrown/active objects and nearby targets remain ordinary physical views; no MultiMesh batch or substitute ownership state was added. Synchronous view construction fell from 19.0–20.1 s for all 5,376 views to 6.14 s for 1,551 nearby views. The development RTX 3070 measured 12.22 ms p95 across a 120-frame sample, which is not evidence of the GTX 980 18 ms target.

Playable setup/actions/observed: the existing physics lab opened the full beach and checked zero awake bodies, 5,376 WORLD records, all within-95 m views, then moved the player to a distant litter ID. Its physical body appeared on approach; returning to the start removed that resting body while the ID stayed WORLD and the snapshot passed invariants. Subsequent scene checks passed 631.1 m traversal, buried reveal, all 24 rescue cuts, the 500-ID reef completion, scanner filters, physical throw/save/reload, P10 slot capture, P12 sorting and the manifest/ownership checks. The scanner global query was corrected to avoid accidentally instantiating every distant match.

Still open: exported Windows profiling on the requested GTX 980-class GPU / 8 GB RAM; cold-start perceived latency; 4K/1080p stress matrix with p95 frame times, >50 ms stalls and process/GPU memory return after repeat runs. No target-hardware compliance claim is made from the stronger machine.

Compact-world follow-on supersedes the historical no-batch setup above: the quarter-length beach concentrated the same 5,700 required items and made the earlier view radius costly. `DistantItemVisuals` now batches single-mesh Synty litter by section/definition, with physical `WorldItem` views near the player and stable state IDs throughout. See [compact beach](compact-beach.md) and [performance measurements](../performance.md) for the current counts and live-scene checks. The GTX 980-class/exported performance gate remains open.
