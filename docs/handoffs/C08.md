# C08 checkpoint — first-person carry fit

## Beach hand views — 24 September 2026

At 1280×720, the two small carried props floated above the palms, and the original chair presentation covered the aim point at 70° FOV. The existing small-prop sockets now sit 0.14 m lower. The large-prop socket sits lower and to the right, and its presentation scale is 0.4 instead of 0.65. The chair remains visible while the center of the view stays clear. This is presentation only; world meshes, collision, reach, hand cost and save state are unchanged.

Setup/actions/observed: Godot 4.6.1 Mono Compatibility renderer, `scenes/main.tscn`, seed `first-shore`, 1280×720, isolated profile, development PC with RTX 3070. A one-off scene probe started a real run, set FOV to 70° and 110° through `SettingsStore`, staged a world bucket and beach ball in the two hands using `ItemStore.try_hold`, released them with the normal carry transaction, then staged a world beach chair. The probe refreshed the normal hand visuals and captured the game viewport after physics/render frames. All three holds and the release succeeded; the final run had zero state-invariant errors. This is rendered visual evidence with direct service setup, not controller pickup or player-paced play.

Held bag instances now hide the world label and use a narrow category-coloured chip. Setup/actions/observed: Godot 4.6.1 Mono Compatibility renderer, seed `first-shore`, 1280×720, isolated profile.
