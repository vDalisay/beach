# C01 — Target eligibility and primary action

Status: **implemented and checked with real game state** on 23 September 2026, Godot `4.6.1.stable.mono.official.14d19694e`, Compatibility/OpenGL, content `beach-content-5` / generator `manifest-1`. F01/F03 no longer reproduce in the checked input routes. Human-paced full play and physical controller input remain C09 gates.

`ItemStore.collection_tool_for` is the one state-sensitive collection rule used by authoritative bagging, aiming and area-tool filtering. A hidden BURIED find still needs detection; an ATTACHED rescue still needs the knife; a revealed find or detached attachment needs the stick to enter the bag; standalone residue remains cloth-only. Valuables remain excluded from sand/vacuum. Required IDs, definitions, quotas and content version did not change. Occupied hands do not make a selected detector satisfy the stick requirement.

The player now resolves aimed hold, sealed-bag hold, place, clean and eligible direct pickup before tool fallback. Sand/vacuum retain their area collection path for small ordinary waste. Vacuum runs after the player input step and suppresses the current held press when a contextual action takes it, preventing a prop or bag click from causing a second transfer. Detector feedback says to switch to the stick after uncovering; its uncover prompt uses the current primary binding. The knife gives the same direction for a full-bag dropped attachment. Dirty furniture still uses alternate carry or aimed cloth cleaning, as before.
