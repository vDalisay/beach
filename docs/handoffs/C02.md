# C02 — Table focus, pause and save

Status: **implemented and checked in the main scene** on 23 September 2026 with Godot `4.6.1.stable.mono.official.14d19694e`, Compatibility/OpenGL, content `beach-content-5` / generator `manifest-1`. Physical controller play remains a C09 release gate.

The table grid now owns focus only while navigating cells. Crossing its top, left, right or bottom edge moves native focus to Unload, the selected bin, bin contents or valuables tray. Native controls return to the grid through directional focus; focused buttons receive Godot's ordinary confirm event. Mouse drag and controller selection still call the same sorting service. The table hints use the current input bindings and ordinary inspection shows the item's display name.

Start opens the existing pause menu while sorting, cancels an uncommitted drag preview and freezes the run through the existing tree pause. Resume restores the overhead camera, table input context, visible mouse and prior focus. Closing Settings from this pause keeps world input disabled. Save and quit records the table, bins and tray, then returns to the title. Loading returns to world view at the station with those records intact.

The save/load check exposed a concrete ID-type mismatch: JSON restored table cell keys and tray/bin values as strings, while station removal uses `StringName`. A saved valuable could sell but remain in its tray owner list. `RunState.from_snapshot` now restores those station IDs as `StringName`, so a saved cell can be sorted and a saved valuable sold without duplicate ownership.

`tests/validate_sorting.gd` starts `scenes/main.tscn` with the real 5,700-item state and S1 station. Setup uses existing item-store collection to fill the bag; controller actions are `InputEventJoypadButton` events sent through Godot's input dispatcher. The test uses a separate `user://test_runs/c02` save root. `tests/validate_sealing.gd` exercises the real rack and containers.
